## 📦 Instalación (Termux)

```bash
termux-setup-storage
```
```bash
apt update && apt upgrade -y
```
```bash
pkg install git nodejs ffmpeg imagemagick yarn -y
```
```bash
git clone https://github.com/JoseEsteban/ObitoBot-MD
cd ObitoBot-MD
```
```bash
yarn install && npm install
```
```bash
npm start
```

### Reactivar si se detuvo

```bash
cd ObitoBot-MD && npm start
```

### Modo 24/7 con PM2

```bash
termux-wake-lock
npm i -g pm2
pm2 start index.js
pm2 save
```
